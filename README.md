# Arjun Codes - Creator Website

A modern, responsive website for a tech content creator, built with HTML, CSS and JavaScript.

**Live Demo:** https://vinodsable.github.io/creator-portfolio-website/

## Features
- Dark and light mode (saved in the browser)
- Video cards with a popup YouTube player
- Animated stats counter and scroll reveal effects
- Sticky glass-style navbar with mobile menu
- Collaboration section and contact form (Formspree)
- Fully responsive on mobile, tablet and desktop

## Built With
- HTML5
- CSS3 (Variables, Flexbox, Grid, Media Queries)
- JavaScript (DOM, IntersectionObserver, localStorage)
